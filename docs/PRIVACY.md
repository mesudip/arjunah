# अर्जुनः (Arjunah) Privacy Policy

Last updated: September 19, 2026

अर्जुनः is a user-controlled browser extension and optional desktop companion that let you use your own AI provider with compatible websites. This policy describes the data processed by the अर्जुनः browser extension.

## Data अर्जुनः processes

Depending on the features you choose to use, अर्जुनः may process:

- provider credentials, such as an OpenAI API key;
- your chat messages, images you attach, and the responses returned by your selected model;
- the origin and access permissions you approve for a website;
- the provider and model settings you choose;
- local usage records, such as request and token counts;
- page text, images, links, or other website content only when you explicitly enable page-context sharing; and
- tool requests and results required to run tools disclosed by an approved website.

## How data is used

अर्जुनः uses this data only to provide its core purpose: connecting approved websites to an AI provider chosen by you, under the permissions you grant. Data is not used for advertising, credit decisions, or purposes unrelated to this functionality.

## Storage and transmission

Credentials, settings, website grants, and the usage ledger are stored locally in extension-managed browser storage. Credentials are not exposed to website JavaScript or included in page-visible errors.

When you make an AI request, अर्जुनः sends the information needed for that request to the provider you selected. This can include your message, the website's disclosed assistant instructions, any page context you explicitly enabled, and approved tool input or output. Those providers process data under their own privacy policies and account terms.

Compatible websites can receive model responses and approved tool interactions needed for the feature you invoked. अर्जुनः does not operate a hosted backend and does not sell user data.

The optional अर्जुनः Desktop companion communicates with the extension over a paired loopback connection on your device. If you choose a locally installed subscription provider, that provider's software and service may process request data under its own terms.

## User control and deletion

Website access is granted per exact origin. You can review or revoke a site's access, disable page-context sharing, change providers, remove credentials, and clear local settings through the extension. Uninstalling the extension removes its extension-managed local data according to the browser's normal uninstall behavior.

## Data security

अर्जुनः uses extension-owned interfaces for credentials and consent, document-bound tool execution, exact-origin grants, and explicit disclosure of site prompts and tools. No security measure is perfect; protect access to your browser profile and provider accounts.

## Changes

Material changes to this policy will be published in this repository and reflected by an updated date above.
