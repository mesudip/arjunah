Authentication (optional)
A key is saved for this server.

How this works

Pull a model first, for example ollama pull qwen3-vl:2b. अर्जुनः reads each model's own capabilities from the server, so images go only to vision models and site tools only to models that accept them.

To reach a server on another computer, start it with OLLAMA_HOST=0.0.0.0. Plain http is accepted only for this computer and local-network addresses.

Ollama refuses requests that carry a browser extension's origin, so अर्जुनः removes that header on its own requests to this one address. You don't need to change OLLAMA_ORIGINS, and web pages' requests to the server are untouched.

Disconnect this server

Forgets the address, its key, and its model list. Sites that answer with it stop working.

Catalog

Set it up

Needs Node.js 22.22 or later on macOS, Linux, or Windows.

  1. Install it. arjunah-desktop install starts it now and at every login. 
    npm install -g arjunah-desktop@beta
arjunah-desktop install
  2. Open the dashboard at 127.0.0.1:48123. It shows a six-digit pairing code.
  3. Enter the code and choose Pair.

Unpair this browser

Subscriptions stop working here until you pair again. You can also revoke this browser from the dashboard.

    About

    अर्जुनः

    Bring your own AI provider or subscription to the web. Websites see only the models you expose to them.

    Privacy

    • Keys stay in this browser profile and sync only to a desktop app you paired.
    • Websites see model names, never your keys, accounts, or quotas.
    • No analytics, and no relay operated by the extension.
    • Desktop providers run your locally installed CLIs with their file and shell tools disabled.

    This build

    Implements the अर्जुनः Protocol: tiered site access, a unified model catalog, widget options, and extension-collected tool inputs that stay out of model traffic.
