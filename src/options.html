Bring your own AI provider or subscription to the web. Websites see only the models you expose to them.

Providers and default model

Wallet

Every website you approve uses the global default model unless you pick another one for that site in the toolbar popup or the chat header. Account details stay here; sites see model names only.

Desktop app

Subscriptions

अर्जुनः Desktop runs on this computer and shares your Claude Code, Codex, or OpenCode sign-in with paired browsers. Settings saved here sync to the app and back.

Open dashboard

Start the app with npm run desktop from the repository, then enter the six-digit code it prints. Pairing is per browser profile and can be revoked from either side.

OpenCode Zen API key

API key

Use an OpenCode Zen API key with its native model formats. अर्जुनः routes GPT, Claude, Gemini, Grok, Muse, Qwen, and open-model families through the format each model requires. The key stays in this browser profile and syncs only to a desktop app you paired.

Create a key at OpenCode Zen. Saving the key loads the models your account can call and selects one for you; pick a different default above and save again to change it. Testing sends a short tool-enabled request to the selected model.

OpenAI API key

API key

Your credential stays in this browser profile and syncs only to a desktop app you paired. Use a restricted key and provider-side spending limits.

Test connection sends a short sample request to the selected model. GPT-5.6 tool requests use non-reasoning mode for compatibility.

Site grants

Access

Grants are exact-origin permissions with an access level and the model you chose for that site. Revoking forces the site to ask again.

Diagnostics

Logs

What the extension and the desktop app are doing, newest last. Useful when a reply takes a long time: the desktop log names the stage a local agent is in. Entries hold names, models, counts, and timings only — never prompts, replies, keys, or page content. They stay in this browser and on this computer.
