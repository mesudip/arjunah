Protocol

v1.0.0

This build implements अर्जुनः Protocol v1.0.0: tiered site access, a unified model catalog, widget options, and extension-collected tool inputs that stay out of model traffic. It has no analytics or extension-operated relay. Desktop providers run locally installed CLIs with their file and shell tools disabled.
